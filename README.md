# Form Đăng Nhập Kéo Đèn

Demo form đăng nhập tương tác: mở trang đèn đã sáng, form đăng nhập hiện ra. Kéo dây đèn xuống để tắt đèn thì form biến mất; kéo lại để bật sáng.

- Đèn lắc qua lại nhẹ nhàng khi sáng (nhanh hơn lúc mới vào, rồi êm dần).
- Trên PC: ô cửa sổ gỗ với cây xanh bên trái.
- Bản demo tĩnh (HTML/CSS/JS), không gửi dữ liệu đăng nhập đi đâu.
